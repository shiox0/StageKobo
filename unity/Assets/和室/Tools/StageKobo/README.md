# すてーじ工房 インポーター v0.9.0（Unity / VRChat 用）

ブラウザ版「すてーじ工房」で作ったステージを、Unity 上で組み立て直すエディタ拡張です。
GLB（形）と Unity用JSON（配置・演出）の2つから組み立てます。

## v0.9.0 で増えたもの

- **好きなパーティクルを特効ボタンにできる**（メニュー **和室 → すてーじ工房 → 特効（パーティクル）の設定**。インポーターの「＋ 好きなパーティクルを特効ボタンにする…」からも開けます）
  1. ワールドの、出したい場所にパーティクル（Particle System。アセットストアや BOOTH のエフェクトでも OK）を置く（ステージ `StageKobo_～` の外に）
  2. 「特効の設定を作る」→「＋ ボタンを足す」→ **ボタンの名前**と**出すパーティクル**を決める（ヒエラルキーで選んでから押すと、最初から入ります。1 つのボタンで何個でも）
  3. 「**リモコン・卓に反映**」を押す → 前回と同じ設定でステージを組み立て直して、**正面のリモコン**と**ステージ裏の照明卓**（「追加の特効」の段）にボタンが増えます
  - 出し方：**押すたびに 1 回出す**（ループするパーティクルは「止めるまでの秒」を入れる）／**ON / OFF**（出しっぱなし。もう一度押すと止まる。ランプが付き、あとから入った人にも見える）
  - パーティクルの中にある音（AudioSource）も一緒に鳴らせます
  - UdonSharp 版は全員の画面で出ます（Animator だけの版は押した人の画面だけ・1回出すだけ）
  - 「最初からある特効（スパーク・紙吹雪・スモーク）のボタンも出す」を外すと、ボタンを追加の特効だけにできます（差し替え）
  - 設定はシーン直下の `StageKobo_FX（特効の設定）`（EditorOnly：ワールドには入りません）に保存されるので、ステージを作り直しても消えません。ボタンは 16 個まで
- インポーターが前回の設定（GLB・JSON・チェック）を覚えるようになりました（ウィンドウを開き直しても欄が空になりません）

## v0.8.0 で増えたもの

- **演者を照らすスポットライト**（本物の Spot Light 2 灯）：ステージの照明はほとんどが「見た目だけの光」なので、ステージに立ったアバターは照らされず暗く見えていました。客席の上（ステージの手前・高いところ）から本物のライトで照らします
  - ふだんは**ステージに固定**（演者ダミーの位置。いなければステージのまん中の左右）
  - UdonSharp 版：リモコン・照明卓の **「自分→スポット1」「自分→スポット2」** を押した人を追います（カメラのアップと同じしくみ。もう一度押すと固定に戻る・「固定に戻す」で両方とも固定に）。登録した人がワールドから抜けたら固定に戻ります
  - **スポット ON / OFF**、照明ぜんぶの「暗転」で消え、「ストロボ」で点滅します。音（AudioLink）では明るさを変えません
  - インポーターの「演者を照らすスポットライト」と「スポットの明るさ」（暗く見えるときは上げる）
- **文字・ロゴ（ネオン）**：GLB では半透明の板になっていた（光らない・動かない）のを、ブラウザ版と同じ**加算で光る文字**にしました。動き（拍で脈打つ・点滅・虹色）が付き、**音に大きく反応**します（脈打つは低音で脈打つ）
- **ネオン装飾**：**回転・ふわふわ**も動くようになりました（Animator）。明るさは**音で大きく変わります**
- 反映するには、組み立て直してください

## v0.7.1 で増えたもの

- **LEDバーが動くようになりました**（今までは書き出した瞬間の色で止まっていました）。ブラウザ版と同じ光り方：
  - キューに合わせる（照明の色・明るさに従う）／流れる／**レベルメーター**／常時点灯
  - 照明の「色の付け方」「パレット」「明るさ」「暗転・ストロボ」も、ムービングライトと同じように効きます
  - **演者を照らすスポット**：本物のライト（ピクセルライト）が 2 灯増えます。照らされたもの（アバター・床）は少し重くなります。Quest で重いときは外して組み立ててください
- **音に反応（AudioLink）**：レベルメーターは**本物の音**で上下します。配列で並べたものは、並びの順に低い音 → 高い音（ミラーの左右は同じ並び＝中から外へ広がるイコライザー）。ほかの光り方は低音で明るさが跳ねます
- **ストロボ／ブラインダーが光るようになりました**：小節の頭でフラッシュ（「小節頭でフラッシュ」のとき）、明るさ「ストロボ」・照明ぜんぶ「ストロボ」で点滅。音があると、小節の頭の代わりに**強いキック**で光ります
- **ネオン装飾の「動き」**：拍で脈打つ・点滅・虹色が Unity でも動きます（脈打つは、音があると低音で脈打つ）。回転・ふわふわは動きません
- **ステージのふち・階段の LED・ネオンなどの光るもの**：音への反応を分かりやすくしました（低音でふわっと明るくなる）
- 固定色のライトのレンズも、ビームと同じく低音で跳ねるようにしました。**ピンスポットは音で明るさを変えません**（演者を照らす明かりなので）
- 反映するには、組み立て直してください（AudioLink・YamaPlayer の設定はそのまま使えます）

## v0.7.0 で増えたもの

- **曲の音に反応（AudioLink）**：インポーターの「AudioLink（曲の音）に反応する」（反応の強さ 0.1〜1）
  - ビーム・灯体のレンズ：低音（キック）で明るさが跳ねる。ステージの真ん中から外の灯体ほど少し遅れて伝わる
  - 床のカラーウォッシュ：低音でふわっと明るく ／ ネオンなどの光るもの：低音でふわっと明るく（v0.7.0 は高音でやさしく）
  - 客席の人・ペンライト：低音で弾む（1人ずつ少しずつずれて）。ペンライトの明るさは歌・メロディ（中高音）で少し揺れる。振りは拍のまま
  - LED の VJ パターン・VJ の映像の素：「拍のドン」が低音になる。**イコライザー（EQ）は本物の音**になる
  - 照明卓の拍のランプ：低音で光る（音が届いているかの確認に）
  - 曲が止まっている・一時停止中・音が鳴っていないときは、いつもの BPM の演出のまま（暗くなりません）
  - リモコン・照明卓の **「音に反応 ON / OFF」**（UdonSharp 版。全員に同期）
- **YamaPlayer と連携**：「YamaPlayer の音で動かす」にチェックすると、組み立てのときに
  - シーンに AudioLink が無ければ置く（ステージの外。作り直しても消えません）
  - シーンの YamaPlayer の「設定 → 外部設定 → Audio Link」をオンにして、その AudioLink を選ぶ
  - AudioLink の「Auto Set Media State」を切る（再生・一時停止・停止を YamaPlayer が AudioLink に伝えるため）
  - インポーターの **「AudioLink をつなぐ」** ボタンで、ステージを作り直さずにつなげます（あとから YamaPlayer を置いたとき）。**「YamaPlayer を置く」** ボタンもあります
- AudioLink・YamaPlayer が入っていないプロジェクトでもエラーにはなりません（反応しないだけ）

## v0.6.0 で変わったこと

- **モニターをメインとサブで別々に切り替え**：「メインはカメラ・サブは VJ」「サブだけカメラ」などができます
  - リモコン・照明卓・VJ卓の「メイン」「サブ」それぞれに ライブ映像 / VJ映像
  - どのモニターがサブかは、ブラウザ版でモニターを選んで「リモコンの区分」で決めます（自動：左右ミラーで複製したモニターはサブ）
  - Animator：メインは `Monitor_Live` `Monitor_VJ`（今まで通り）、サブは `Monitor2_Live` `Monitor2_VJ`
- **カメラのアップが「登録した人」の顔を追う**（UdonSharp 版）：リモコン・照明卓の「自分→カメラ1」「自分→カメラ2」を押した人の顔を、アップ（オートの中のアップも）で胸から上で追います
  - もう一度押すと外れます。「登録を外す」でカメラ1・2 とも外れます。登録した人がワールドから抜けたら自動で外れます
  - 引きのショット（周回・クレーン・客席など）は今まで通りステージ全体
  - ブラウザ版でも、カメラの「アップで追う人」で演者ダミーの顔を追えます（Unity の焼き込みにも使われます）
- **VJ の「合成」を外しました**（合成卓・合成レシピ・アニメカラー）。VJ卓・照明卓の 2 台になります。古い JSON の「合成」はトンネルになります

## v0.5.1 で直したこと

  - ステージカメラは、そのカメラを映している LED モニターの縦横比で撮ります（縦の画角はそのまま、横の範囲だけが変わる）
  - 同じカメラを形のちがうモニターに映すときは、いちばん横長のモニターに合わせ、ほかのモニターはまん中を切り抜きます
  - 画像のモニターも、画像のまん中をモニターの縦横比で切り抜きます（伸び縮みしない）
  - ステージ裏の照明卓のカメラ確認モニターも、カメラの縦横比で映します
  - 画像を 2 のべき乗に伸ばさずに取り込むようにしました（縦横比を正しく計算するため）

## v0.4.1〜0.4.2 で直したこと

- **Unity は最初から GLB を読めない**ので、GLB の欄に入れられないことがありました。
  - インポーターが「GLB を読むパッケージ（glTFast）」が入っているかを調べて、無ければ **「glTFast を入れる」ボタン**を出します（押すだけで入ります）
  - GLB の欄に「まだモデルになっていない GLB」を入れると、理由と直し方（入れる／読み込み直す）を出します
  - glTFast は 6.13.1 を入れます（新しい版は Burst を上げるため、VRChat SDK の入ったプロジェクトに合わせて固定）
- ステージカメラに、自分のアバター（一人称用の頭が消えた姿）や VRChat のメニューが映らないようにしました（PlayerLocal・UiMenu レイヤーを外す）
  - VRChat SDK の「Setup Layers for VRChat」を押してから組み立ててください（押す前に組み立てたときは結果に注意が出ます）

## v0.3 で増えたもの

- LED モニターの映像が上下逆になる問題を修正

## 必要なもの

- Unity 2022.3（VRChat で使われているバージョン）
- GLB を Unity に取り込むためのパッケージ（どちらか1つ）
  - **glTFast**（おすすめ）：インポーターの「glTFast を入れる」ボタンで入ります（手で入れるときは Package Manager の「＋」→「Add package by name」に `com.unity.cloud.gltfast` と入力）
  - **UniGLTF**（UniVRM に含まれます）
- すてーじ工房 **v0.7 以降**で書き出した GLB と Unity用JSON（`*.unity.json`）
  - v0.2〜v0.6 の書き出しでも組み立てられますが、VJ と VJ卓は v0.7（モニターのメイン／サブ・アップで追う人は v0.8）、質感は v0.4、ペンライトの揺れ・人の弾み・演者のダンスは v0.3 以降で書き出すと付きます
- UdonSharp 版を使うとき：**VRChat Creator Companion で作ったワールドのプロジェクト**（UdonSharp が最初から入っています）
- 音に反応させるとき：**AudioLink**（VCC で追加。3.x で確認）。曲を流すのは **YamaPlayer**（1.5 で確認）か、AudioLink につないだ動画プレイヤー

## 使い方

1. ブラウザ版の「保存・書き出し」タブで **GLB** と **Unity用JSON** を書き出す
   - 客席を動かしたいときは「観客・イスも含める」にチェック
2. この unitypackage を Unity に取り込む
3. GLB と `.unity.json` を Assets フォルダにドラッグする
4. メニュー **和室 → すてーじ工房 → インポーター** を開く
5. **（初回だけ）**「UdonSharp 版を有効にする」ボタンを押す → スクリプトの再コンパイルが終わるまで待つ
6. 「GLB」と「Unity用JSON」の欄にそれぞれドラッグして **組み立てる** を押す

シーンに `StageKobo_<ステージ名>` ができます。
作られたマテリアル・アニメーション・RenderTexture は `Assets/和室/StageKobo_Generated/<ステージ名>/` に保存されます。
同じステージ名で作り直すと、前のものは置き換わります（Ctrl+Z で戻せます）。

| 当たり判定 | 床・階段・台に MeshCollider（歩けるようにする） |

## ステージ裏の操作卓

背景の裏（ステージの奥）に、客席側を向いて 2 台並びます。卓の手前の黄色い線のあたりに立つと、奥のモニターまで見渡せます。

| 卓 | 中身 |
|---|---|
| 照明卓（左） | テンポ（−5 −1 TAP +1 +5・BPM 表示・拍のランプ）・動きの速さ・照明ぜんぶ・特効・音に反応（ON・OFF。AudioLink を使うとき）・追加の特効（特効の設定で作ったもの）・動き・色の付け方・パレット・明るさ・レーザー・ウォッシュ・ペンライト・メイン／サブ（ライブ映像・VJ映像）・カメラ1/2・アップで追う人（自分をカメラ1・自分をカメラ2・登録を外す）・スポットライト（自分をスポット1・自分をスポット2・固定に戻す・ON・OFF） ／ モニター：カメラ1・カメラ2 |
| VJ卓（まん中） | パッド（フラッシュ・反転・グリッチ・ズーム・ストロボ・暗転）・デッキ（A/Bを編集・◀A ⇄ B▶・⇄映す・選んだら切り替え）・切替の長さ・拍で交互・映像の素・速さ・数・ズーム・画像・色・エフェクト・ミラー・万華鏡・ドン・文字・オートVJ・シーン・メイン／サブ・背景LED・映し方 ／ モニター：VJ 出力・デッキA・デッキB |

- ボタンを押せる距離は約 2.5m です（UdonBehaviour の Proximity）
- 卓の近く（9m 以内）にいる人だけ、確認用モニターのためにデッキA・B を両方描きます（離れると映っている方だけ）
- 卓の位置を変えたいときは `Backstage（ステージ裏の操作卓）` ごと動かしてください（中のボタンの位置関係は変えない）

### 2つの版のちがい

| | UdonSharp 版（おすすめ） | Animator だけの版 |
|---|---|---|
| 操作の同期 | 全員に同期・あとから入った人にも届く | 押した人の画面だけ |
| テンポ | BPM ±・TAP で変えられる | 書き出したときの BPM のまま |
| 動きの速さ | ×½ / ×2 | ×1 のまま |
| 使える条件 | UdonSharp が入っている（VCC のワールドなら最初から） | どこでも |

UdonSharp が無いプロジェクトでは、自動的に Animator だけの版になります（エラーにはなりません）。

### Animator のトリガー（自分で Udon から呼ぶとき）

チャンネルごとに Animator のレイヤーが分かれています。

## VRChat で使うとき

- **ブルーム（にじみ）**：Post Processing v2 の Bloom を入れると、ブラウザ版に近い見た目になります。目安は Intensity 3〜6、Threshold 1.0 です
- **リモコンを触れるようにする**：VRChat SDK が入っていれば、Canvas に `VRC Ui Shape` が自動で付きます
- **Unity で試す**：UdonSharp 版は ClientSim（VRChat SDK に同梱）で再生ボタンから試せます。`EventSystem（Unity確認用）` は EditorOnly タグなのでワールドには入りません
- **質感**：GLB のマテリアル（glTFast / UniGLTF が作るもの）にテクスチャが付いています。差し替えたいときはそのマテリアルを編集してください
- **Reflection Probe**：Quest で重いときは、Type を Baked にして Generate Lighting するか、`FloorReflectionProbe` を消してください
- **重さの目安**：観客 約380人で ペンライト約2万頂点・人のシルエット約6万頂点（どちらも1つのメッシュ）。Quest 向けは観客の人数を減らしてください
- **VJ の重さ**：640×360 の Custom Render Texture を毎フレーム 2〜3 枚描きます。Quest で重いときはインポーターの「VJ」を外して組み立てると、今まで通りの VJ パターンになります
- **卓のボタン**：1個ずつ UdonBehaviour（StageKoboButton）が付きます（2台で約 230 個。Update は使わないので軽い）
- **音に反応（AudioLink）**：
  - YamaPlayer の音量を下げても、反応の強さはほとんど変わりません（AudioLink が音量の分を戻します）。ミュートした人の画面では、いつもの演出に戻ります
  - 「明るさ」を **点灯** にすると、音への反応がいちばん分かりやすくなります（「脈打つ」などは拍の明滅に音の明滅が重なります）
  - テンポ（BPM）は自動では合いません。動き・色替え・カメラワークは今まで通り BPM で動くので、曲に合わせて TAP してください
  - 反応の強さを変えるときは、インポーターで強さを変えて組み立て直します（マテリアルの「音に反応（AudioLink）の強さ」を直接変えても OK）
  - AudioLink の感度は、AudioLink の Controller（AudioLinkController.prefab）を置くとワールドの中で調整できます
  - 重さ：音を読むのは頂点ごとに数回だけ（客席・ペンライトは人数分）。Quest で重いときは客席の人数を減らすか、「音に反応」を外して組み立ててください（外すと読みません）

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| GLB を欄に入れられない・GLB がモデル（▶ の付いたプレハブ）にならない | GLB を読むパッケージが入っていません。インポーターの「glTFast を入れる」を押す（1〜2分） |
| glTFast を入れたのに GLB がモデルにならない | GLB を右クリック →「Reimport」、またはインポーターの「この GLB を読み込み直す」 |
| VRChat SDK に「Layers」「Collision Matrix」の注意が出る | 新しいワールドのプロジェクトでは最初に1回必要な設定です。「Setup Layers for VRChat」→「Set Collision Matrix」の順に押す |
| カメラのアップが顔を追わない | UdonSharp 版で、リモコンか照明卓の「自分→カメラ1／2」を押した人だけを追います。カメラが「アップ」か「オート」のアップの間だけ追います |
| サブのモニターが切り替わらない | ブラウザ版でそのモニターの「リモコンの区分」を確認（自動では左右ミラーのものだけがサブ） |
| モニターの映像が横に伸びる・縦につぶれる | v0.5.1 で直りました。組み立て直してください（ブラウザ版 v0.7.1 で書き出すと、ブラウザと同じ画角になります） |
| モニターのライブ映像に自分の頭のないアバターやメニューが映る | レイヤー設定（上）をしてから組み立て直す |
| 左右（または前後）が逆になる | インポーターの「軸の向き」を X反転 / Z反転 に切り替えて作り直す |
| LED モニターの映像が上下逆 | LED のマテリアルの「UVの上下を戻す」のチェックを切り替える |
| ペンライトが根元ではなく先っぽを中心に揺れる | ペンライトのマテリアルの「UVの上下を戻す」のチェックを切り替える |
| 床がのっぺりして映り込まない | `FloorReflectionProbe` があるか確認する（無ければインポーターの「床の映り込み」をオンにして作り直す） |
| 「JSON が古い形式です」と出る | すてーじ工房 v0.2 以降で GLB と JSON の両方を書き出し直す |
| ピンク色のマテリアルになる | Shaders フォルダが取り込まれているか確認する |
| 「UdonSharp 版を有効にする」が出ない | UdonSharp が入っていません。VCC でワールドのプロジェクトを作るか、UdonSharp を追加してください |
| 有効にしたのにチェックが出ない | Console に赤いエラーが出ていないか、Runtime フォルダが取り込まれているか確認する |
| UdonSharp を外したらエラーが出る | Project Settings → Player → Scripting Define Symbols から `STAGEKOBO_UDON` を消す |
| 音に反応しない | ①インポーターの「AudioLink（曲の音）に反応する」にチェックして組み立てたか ②シーンに AudioLink があって表示（チェック）されているか ③YamaPlayer の「設定 → 外部設定 → Audio Link」がオンで AudioLink が選ばれているか（インポーターの「AudioLink をつなぐ」で設定できます）④リモコン・照明卓の「音に反応」が ON か。照明卓の拍のランプが音で光っていれば届いています |
| 曲を止めても反応が止まらない・再生しても反応しない | AudioLink の「Auto Set Media State」を切って、YamaPlayer に再生の状態を任せる（「AudioLink をつなぐ」で自動で切れます） |
| 静かな曲で暗くなりすぎる | 反応の強さを下げて組み立て直す（0.4 くらい） |
| ステージに立つとアバターが暗い | 「演者を照らすスポットライト」にチェックして組み立て直す。それでも暗いときは「スポットの明るさ」を上げる（lilToon などは明るさに上限があるので、上げすぎても白飛びはしにくい） |
| スポットが追ってこない | UdonSharp 版で、リモコンか照明卓の「自分→スポット1／2」を押した人だけを追います。ステージから 25m 以上はなれると固定の場所に戻ります |
| 追加の特効のボタンが出ない | 特効の設定で、ボタンにパーティクルが入っているか確認して「リモコン・卓に反映」（組み立て直し）を押す |
| 追加の特効がワールドに入った瞬間に出る | パーティクルの Play On Awake を切る（特効の設定ウィンドウの「ボタンを押したときだけにする」） |
| 追加の特効が止まらない | ループするパーティクルです。「止めるまでの秒」を入れるか、出し方を「ON / OFF」にする |
| 追加の特効が出ない | パーティクルのオブジェクトがオフ（非表示）になっていないか、ステージ（StageKobo_～）や特効の設定のオブジェクトの中に置いていないか確認する |
| スポットの光がワールドの天井・壁にさえぎられる | `FollowSpots（演者を照らすスポット）` ごと、さえぎられない場所へ動かす（向きは自動で合います） |
| LEDバー（レベルメーター）が止まったまま | v0.7.1 で動くようになりました。組み立て直してください |
| レベルメーターの高い音の方があまり動かない | 曲によっては高い音が小さいためです。AudioLink の Controller（AudioLinkController.prefab）で Gain を上げると全体に大きく動きます |
| 観客がいない | ブラウザ版の書き出しで「観客・イスも含める」にチェックを入れる |
| VJ卓ができない／LED に VJ が映らない | すてーじ工房 **v0.7 以降**で GLB と JSON を書き出し直して、組み立て直す（結果に「VJ の情報がありません」と出ます） |
| ステージ裏の操作卓ができない | UdonSharp 版のときだけ作られます。「UdonSharp 版にする」と「ステージ裏の操作卓」にチェック |
| 卓のボタンの文字が出ない | `Textures/SK_Labels.png` が取り込まれているか確認する |
| 卓が客席から見える | 背景が「なし」のステージでは隠すものがありません。背景を置くか、`Backstage` を動かす |
| モニターに VRChat のカメラが映る | VRChat SDK の「Setup Layers for VRChat」を押してから組み立て直す（カメラが映らないレイヤーの設定を使うため） |
